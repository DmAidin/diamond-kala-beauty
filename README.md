# دایمند کالا — فروشگاه لوازم آرایشی و بهداشتی

⚠️ این نسخه یه سایت **جدا و مستقل** از نسخه‌ی اصلی (فروشگاه عمومی) هست — کد یکسانه، فقط تم/محصولات فرق داره. باید:
- ریپازیتوری گیت‌هاب جدا داشته باشه
- پروژه‌ی Vercel جدا داشته باشه
- `DATABASE_URL` جدا (دیتابیس یا حداقل اسم دیتابیس متفاوت) داشته باشه، وگرنه محصولات این دو فروشگاه با هم قاطی می‌شن

## راه‌اندازی

1. `npm install`
2. فایل `.env.example` را به `.env.local` کپی کن و مقادیرش را پر کن (حداقل `DATABASE_URL` و `NEXTAUTH_SECRET`)
3. `npx prisma generate`
4. (اختیاری) `npm run seed` برای پر کردن فروشگاه با چند محصول نمونه
5. `npm run dev`

## درگاه پرداخت

پرداخت از طریق زرین‌پال پیاده‌سازی شده (`src/utils/zarinpal.js`، `/api/payment/request`، `/api/payment/verify`).
تا وقتی `ZARINPAL_MERCHANT_ID` را در `.env.local` تنظیم نکنی، پرداخت‌ها به‌صورت خودکار روی **sandbox** زرین‌پال انجام می‌شوند (پول واقعی جابه‌جا نمی‌شود) تا کل مسیر خرید را بدون داشتن پذیرندگی واقعی تست کنی. برای رفتن به حالت واقعی، مرچنت آیدی واقعی از zarinpal.com بگیر و `ZARINPAL_SANDBOX=false` را تنظیم کن.

## نکات فنی مهم برای ادامه‌ی کار

- محصولات و سفارش‌ها در MongoDB (mongoose) ذخیره می‌شوند؛ کاربران و احراز هویت با Prisma روی همان دیتابیس.
- سبد خرید در Redux + localStorage نگه‌داری می‌شود و به کاربر لاگین‌شده وصل است (با تغییر اکانت خودش را پاک می‌کند).
- برای ساخت اولین ادمین: از فرم ثبت‌نام با پر کردن «کلید ادمین» (برابر با `ADMIN_SECRET`) استفاده کن.
